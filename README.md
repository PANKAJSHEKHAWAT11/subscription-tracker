# Subscription Tracker

Track your recurring subscriptions and see monthly/yearly spend.

**Live demo:** https://your-link.vercel.app

## Features
- Add and delete subscriptions
- Totals calculated live from your data
- Data saved in the browser (localStorage)

## Built with
React, Vite, CSS

## What I learned
- Lifting state up so sibling components share data
- Passing functions as props
- Controlled inputs
- Persisting state with useEffect + localStorage
